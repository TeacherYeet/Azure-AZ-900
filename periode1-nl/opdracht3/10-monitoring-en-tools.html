Monitoring en tools

De laatste les van deze opdracht gaat over hoe je met Azure werkt (interfaces en infrastructure-as-code) en hoe je in de gaten houdt of alles goed blijft draaien.

Manieren om met Azure te werken

Er zijn meerdere manieren om Azure-resources te beheren, elk geschikt voor een ander doel:

  • Azure Portal — de grafische webinterface, ideaal om resources visueel te verkennen en te beheren.
  • Azure Cloud Shell — een browsergebaseerde command line, met daarin twee opties:
    • Azure CLI — een opdrachtregel-tool voor het beheren van Azure-resources met commando's.
    • Azure PowerShell — vergelijkbaar, maar gebaseerd op PowerShell-scripting.
  • Azure Arc — breidt Azure-beheer uit naar resources buiten Azure, zoals on-premises servers of resources bij andere cloudproviders, zodat je alles vanuit één plek kunt beheren.

Azure Resource Manager (ARM)

Azure Resource Manager (ARM) is de beheerlaag van Azure: het stelt je in staat om resources binnen je subscription aan te maken, aan te passen en te verwijderen. Alles wat je doet via de portal, CLI, PowerShell of een SDK, gaat uiteindelijk via ARM. ARM zorgt voor:

  • Het aanmaken, configureren, beheren en verwijderen van resources en resource groups.
  • Het organiseren van resources.
  • Het controleren van toegang tot resources (via RBAC).
  • Automatisering via verschillende tools en SDK's.
  • Het opslaan van omgevingslay-outs in JSON-bestanden.

ARM-templates

Een ARM-template is een JSON-bestand waarmee je Azure-infrastructuur kunt aanmaken en uitrollen zonder handmatige stap-voor-stap commando's te hoeven schrijven — dit heet infrastructure as code. Kenmerken:

  • Declaratieve syntax — je beschrijft wát je wilt hebben, niet hóe het stap voor stap gebouwd moet worden.
  • Herhaalbare resultaten — dezelfde template levert steeds dezelfde, consistente omgeving op.
  • Orchestratie — ARM regelt zelf de juiste volgorde en afhankelijkheden.
  • Modulaire bestanden — templates kun je opsplitsen en hergebruiken.
  • Ingebouwde validatie — fouten worden vóór het uitrollen gesignaleerd.
  • Exporteerbare code — je kunt de configuratie van bestaande resources exporteren als template.
💡 Waarom infrastructure as code handig is
Met een ARM-template beschrijf je bijvoorbeeld eenmalig "een webapp + database + netwerk", en kun je die exact dezelfde omgeving daarna herhaaldelijk en foutloos opnieuw uitrollen — voor test, staging én productie. Geen risico meer op vergeten instellingen door handmatig werk.

De drie belangrijkste monitoringtools

Azure Advisor

Azure Advisor analyseert je bestaande Azure-resources en geeft persoonlijke, proactieve aanbevelingen op basis van best practices, verdeeld over vijf categorieën: betrouwbaarheid, beveiliging, prestaties, kosten en operational excellence.

Azure Service Health

Azure Service Health is een verzameling diensten die je op de hoogte houdt van de status van Azure, op drie niveaus:

  • Azure Status — een globaal overzicht van de gezondheid van alle Azure-diensten in alle regio's.
  • Service Health — een gericht overzicht van alleen de diensten en regio's die jíj gebruikt. Een storing in een dienst die jij niet gebruikt, zie je hier niet.
  • Resource Health — een overzicht op maat van je eigen, specifieke cloudresources.

Azure Monitor

Azure Monitor maximaliseert de beschikbaarheid en prestaties van applicaties en diensten door telemetrie te verzamelen, te analyseren en erop te reageren — zowel uit cloud- als on-premises omgevingen. Onderdelen zijn onder andere:

  • Application Insights — inzicht in het gedrag en de prestaties van applicaties.
  • Log Analytics — logdata doorzoeken en analyseren.
  • Smart Alerts — slimme meldingen bij afwijkingen.
  • Automation Actions — automatisch reageren op gebeurtenissen.
  • Aangepaste dashboards — de belangrijkste gegevens overzichtelijk bij elkaar.
💡 Advisor, Service Health of Monitor?
Vraag je af: wil ik weten hoe ik het beter kan doen? Dan is dat Advisor. Wil ik weten of Azure zelf een storing heeft? Dan is dat Service Health. Wil ik continu telemetrie verzamelen en analyseren uit mijn eigen applicaties en resources? Dan is dat Azure Monitor.
