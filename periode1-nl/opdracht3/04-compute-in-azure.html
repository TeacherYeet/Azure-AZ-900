Compute in Azure

"Compute" is de rekenkracht waarop je applicaties draaien: processors, geheugen, schijfruimte en netwerk. Azure biedt hiervoor meerdere opties, van volledig zelf beheerde virtuele machines tot kant-en-klare platforms. In deze les leer je de belangrijkste compute-diensten kennen.

Wat is Azure compute?

Azure compute is een on-demand rekendienst: je krijgt naar behoefte toegang tot resources zoals schijven, processors, geheugen, netwerk en besturingssystemen. De belangrijkste compute-diensten zijn: Virtual Machines, App Services, Azure Kubernetes Service (AKS), Container Instances, Azure Virtual Desktop en Azure Functions.

Virtual Machines (VM's)

Een Azure Virtual Machine is een softwarematige nabootsing van een fysieke computer, inclusief virtuele processor, geheugen, opslag en netwerk. Dit is een IaaS-dienst (Infrastructure as a Service): jij krijgt volledige controle en kunt het besturingssysteem en alle software er zelf op installeren en beheren.

Typische toepassingen:

  • Ontwikkelen en testen — snel een computer met specifieke configuratie opzetten om te programmeren en te testen.
  • Applicaties in de cloud — schaalbaar draaien: extra VM's bijzetten bij drukte, uitzetten als de vraag daalt.
  • Uitbreiding van je datacenter — VM's in een Azure virtual network eenvoudig koppelen aan het netwerk van je eigen organisatie.

VM scale sets

Een VM scale set laat je automatisch schalen: bij toenemende vraag worden er automatisch extra, identieke VM's bijgezet (scale out), en bij afnemende vraag worden ze weer afgeschaald (scale in). Het verkeer wordt hierbij load-balanced over de VM's verdeeld.

VM availability sets

Een availability set groepeert VM's zodat een storing er niet allemaal tegelijk uitligt. Dit gebeurt via twee soorten domeinen:

  • Update domain — houdt VM's gegroepeerd die tegelijk herstart kunnen worden zonder dat dit een storing veroorzaakt.
  • Fault domain — groepeert VM's op basis van gedeelde stroomvoorziening en netwerk, zodat niet alle VM's door dezelfde hardwarestoring worden geraakt.

Azure Virtual Desktop

Azure Virtual Desktop is desktop- en app-virtualisatie die in de cloud draait. Je kunt hiermee een complete desktop-virtualisatieomgeving opzetten zonder aparte gateway-servers te hoeven beheren. Het ondersteunt echte multi-session-implementaties, waarbij meerdere gebruikers tegelijk kunnen inloggen op dezelfde onderliggende machine.

Containers

Containers zijn een lichtgewicht, gevirtualiseerde omgeving. In tegenstelling tot een VM hoef je bij een container geen besturingssysteem te beheren — containers zijn ontworpen om snel te worden aangemaakt, op- en afgeschaald, en gestopt.

  • Azure Container Instances (ACI) — een PaaS-dienst waarmee je een container in Azure draait zonder een virtuele machine of extra services te hoeven beheren.
  • Azure Kubernetes Service (AKS) — een orchestratiedienst voor containers, geschikt voor gedistribueerde architecturen met grote aantallen containers.

Azure Functions

Azure Functions is Microsofts serverless compute-dienst: je schrijft alleen de code voor jouw service, en niet voor de onderliggende infrastructuur. De code is event-driven — hij wordt getriggerd door bijvoorbeeld een HTTP-verzoek, een timer, of het uploaden van een bestand. De infrastructuur schaalt hierbij automatisch mee, en je betaalt alleen voor wat je daadwerkelijk gebruikt (micro-billing).

Azure App Services

Azure App Service is een volledig beheerd PaaS-platform om webapps en API's snel te bouwen, te implementeren en op te schalen. Het ondersteunt .NET, .NET Core, Node.js, Java, Python en PHP, en biedt prestaties, beveiliging en compliance op enterprise-niveau.

De compute-opties vergeleken

OptieTypeWanneer gebruik je het?
Virtual Machine IaaS Cloud-server met Windows of Linux, compleet besturingssysteem inbegrepen. Handig voor "lift-and-shift"-migraties naar de cloud, en als je volledige controle wilt.
VM Scale Set IaaS Wanneer je vraag sterk wisselt en je automatisch VM's wilt bij- en afschalen, load-balanced.
Containers (ACI / AKS) PaaS Lichtgewicht, goed voor microservices; ontworpen voor schaalbaarheid en veerkracht via orchestratie.
Azure Virtual Desktop PaaS Wanneer je een volledige Windows-desktopervaring wilt aanbieden vanuit de cloud, toegankelijk via een browser of app, met meerdere gebruikers tegelijk.
Azure Functions Serverless Voor kleine stukjes code die alleen bij een gebeurtenis (event) hoeven te draaien, zonder dat je servers beheert.
App Service PaaS Voor het snel bouwen en hosten van webapps en API's, zonder infrastructuur te beheren.
💡 Koppel dit terug aan IaaS/PaaS/SaaS
Herken je het patroon uit Opdracht 1? Virtual Machines en VM Scale Sets zijn IaaS — jij beheert nog het besturingssysteem. App Services, AKS/ACI en Azure Virtual Desktop zijn PaaS — het platform is al voor je geregeld. Azure Functions gaat nog een stap verder: serverless, waarbij je je zelfs geen zorgen maakt over servers of platforms, en alleen voor het daadwerkelijke gebruik betaalt.
