Opslag in Azure

Naast rekenkracht en netwerk heb je ook een plek nodig om data op te slaan. Azure biedt hiervoor het storage account als basis, met verschillende opslagdiensten, redundantieopties en kostenniveaus. Deze les geeft je het overzicht dat je nodig hebt voor het AZ-900-examen.

Wat is een storage account?

Een storage account is de container waarin al je Azure-opslag wordt ondergebracht. Belangrijke kenmerken:

  • Moet een wereldwijd unieke naam hebben (deze naam vormt namelijk ook het internetadres van je opslag).
  • Biedt toegang via internet, overal ter wereld.
  • Bepaalt welke opslagdiensten en welke redundantieopties je kunt gebruiken.

De opslagdiensten

Binnen een storage account kun je verschillende typen data opslaan, elk via een eigen dienst en eigen publiek endpoint:

DienstWaarvoor?
Blob StorageGeoptimaliseerd voor het opslaan van enorme hoeveelheden ongestructureerde data, zoals tekst- of binaire bestanden (foto's, video's, back-ups).
Disk StorageLevert de schijven die virtuele machines, applicaties en andere diensten gebruiken.
Azure FilesHoogbeschikbare netwerk-bestandsshares, te benaderen via het standaard SMB-protocol — vergelijkbaar met een gedeelde netwerkschijf.
Queue StorageBerichten opslaan die tussen onderdelen van een applicatie worden uitgewisseld.
Table StorageOpslag van grote hoeveelheden gestructureerde, niet-relationele (NoSQL) data.

Redundantie: hoe blijft je data veilig?

Redundantie betekent dat Azure meerdere kopieën van je data bewaart, zodat je data behouden blijft ook als er hardware uitvalt. Hoe meer kopieën en hoe verder ze uit elkaar liggen, hoe hoger de duurzaamheid (durability) — uitgedrukt in "aantal negens" (bijvoorbeeld 99,999999999% = "11 nines").

RedundantieHoe wordt data gekopieerd?
LRS (Locally redundant storage)Meerdere kopieën binnen één datacenter in de primaire regio.
ZRS (Zone-redundant storage)Kopieën verspreid over drie availability zones binnen de primaire regio.
GRS (Geo-redundant storage)Kopieën in de primaire regio én in een tweede, gekoppelde regio.
GZRS (Geo-zone-redundant storage)Kopieën over drie availability zones in de primaire regio, plús een kopie in de secundaire regio.

Onthoud het simpel: LRS is de basisvariant (één locatie), ZRS beschermt tegen uitval van een hele datacenterlocatie, en GRS/GZRS beschermen zelfs tegen het uitvallen van een complete regio, omdat er dan ook nog een kopie in een andere regio staat.

Toegangsniveaus (access tiers)

Voor Blob Storage kun je kiezen uit drie toegangsniveaus, die bepalen hoe je betaalt voor opslag versus het ophalen van data. Je kunt op elk moment tussen niveaus wisselen.

TierVoor welke data?
HotData die vaak wordt gebruikt/geraadpleegd. Hogere opslagkosten, lagere ophaalkosten.
CoolData die weinig wordt geraadpleegd en minimaal 30 dagen wordt bewaard. Lagere opslagkosten, hogere ophaalkosten.
ArchiveData die zelden wordt geraadpleegd, minimaal 180 dagen bewaard wordt, en waarbij een langere ophaaltijd (latency) acceptabel is. Laagste opslagkosten.
💡 Kostenoptimalisatie in de praktijk
Stel je bedrijfsfoto's van vorig jaar op: die raadpleeg je bijna nooit meer, maar je moet ze wel bewaren. Zet ze in de Archive-tier voor minimale kosten. Foto's van de huidige campagne die dagelijks gebruikt worden, zet je in Hot. Zo betaal je niet meer dan nodig voor opslag die je toch nauwelijks gebruikt.

Data migreren naar (en van) Azure

Voor het verplaatsen van bestaande data en systemen naar Azure zijn twee migratie-tools relevant:

  • Azure Migrate — een uniform migratieplatform met geïntegreerde en losstaande tools voor het beoordelen (assessment) en daadwerkelijk migreren van omgevingen naar Azure.
  • Azure Data Box — een fysiek, robuust apparaat waarmee je tot 80 terabyte aan data kunt transporteren. Handig voor het verplaatsen van grote hoeveelheden data vanaf locaties met beperkte of geen internetverbinding, voor disaster-recoverybackups, of om compliance-redenen data juist uit Azure te halen.

Bestanden beheren en synchroniseren

ToolWat het doet
AzCopyCommand-line tool om blobs of bestanden naar/van je storage account te kopiëren.
Azure Storage ExplorerGrafische interface (vergelijkbaar met Windows Verkenner) om je opslag te beheren, werkt op Windows, macOS en Linux.
Azure File SyncSynchroniseert Azure Files en on-premises bestanden in twee richtingen (bidirectioneel). "Cloud tiering" houdt veelgebruikte bestanden lokaal beschikbaar en maakt tegelijk lokale schijfruimte vrij.
