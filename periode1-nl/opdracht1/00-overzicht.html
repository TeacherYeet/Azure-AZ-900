Onderzoek softwarepakketten

Je gaat je verdiepen in de software die van belang is voor je toekomstige beroep. Je oriënteert je op de (toekomstige) arbeidsmarkt en bepaalt welke software voor jouw toekomstig beroep het meest relevant is om mee te werken.

💡 Voor deze cursus
Het cloudplatform Microsoft Azure staat centraal. De lessen op deze pagina's helpen je te onderbouwen waarom cloud- en Azure-kennis relevant is voor jouw toekomstig beroep — gebruik ze als bron voor je onderzoek.

Wat ga je doen?

  1. Beschrijf kort jouw beeld van de werkzaamheden van je toekomstige beroep.
  2. Beschrijf de criteria op basis waarvan je een keuze gaat maken voor de software waarin je je gaat verdiepen.
  3. Maak een overzicht van de softwarepakketten waarmee je in aanraking kunt komen bij het uitvoeren van je toekomstige beroep. Gebruik hiervoor bijvoorbeeld vacatures, profielen op sociale media en informatie uit blogs of tijdschriften.
  4. Bepaal op basis van verzamelde gegevens welke softwarepakketten voor jou in aanmerking komen voor verdieping.
  5. Maak een keuze in welke software je je gaat verdiepen en beargumenteer waarom je tot deze keuze bent gekomen.
