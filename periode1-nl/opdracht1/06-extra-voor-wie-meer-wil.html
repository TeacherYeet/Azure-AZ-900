Vergelijk Azure met andere cloudproviders

Deze opdracht is niet verplicht en telt niet mee voor je examenportfolio. Doe hem als je meer diepgang wilt, of als je in je onderzoek (Opdracht 1) wilt laten zien dat je verder hebt gekeken dan alleen Azure.

★ Bonusopdracht
Microsoft Azure is niet de enige grote cloudprovider. Onderzoek hieronder hoe Azure zich verhoudt tot zijn twee grootste concurrenten.

De "grote drie"

ProviderEigenaarBekend om
Microsoft AzureMicrosoftSterke integratie met Microsoft 365, Windows Server en enterprise-omgevingen.
AWS (Amazon Web Services)AmazonMarktleider qua marktaandeel, breedste dienstenaanbod, populair bij startups en techbedrijven.
Google Cloud Platform (GCP)GoogleSterk in data-analyse, machine learning en Kubernetes/containers.

Opdracht

  1. Zoek op internet naar minimaal twee vacatures binnen jouw toekomstig beroep waarin een specifieke cloudprovider genoemd wordt (Azure, AWS of GCP).
  2. Zoek daarnaast op of er certificeringen bestaan bij de andere providers die vergelijkbaar zijn met AZ-900 (bijvoorbeeld AWS Cloud Practitioner of Google Cloud Digital Leader).
  3. Schrijf een korte vergelijking (half A4 is genoeg): welke provider(s) komen het meest voor in jouw vakgebied, en waarom denk je dat dat zo is?
  4. Optioneel: voeg deze vergelijking toe als extra onderbouwing bij je overzicht van softwarepakketten in Opdracht 1.
💡 Waarom dit de moeite waard is
Werkgevers waarderen het wanneer je verder kijkt dan één platform. Zelfs als je je uiteindelijk in Azure verdiept, laat een korte vergelijking zien dat je een bewuste, onderbouwde keuze hebt gemaakt — precies wat bij stap 5 van Opdracht 1 wordt gevraagd.
