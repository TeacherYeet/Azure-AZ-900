Documenting Architecture, Cost & Security

Building a working prototype is only half the job. In a real IT role, other people — colleagues, a manager, a client — need to understand what you built, what it costs, and whether it is safe to run. This page helps you write that documentation.

Why documentation matters

A cloud resource that only you understand is a risk: if you leave, get sick, or simply forget the details in six months, nobody can maintain it safely. Professional documentation answers three questions any colleague would ask when they open your resource group for the first time:

  • Architecture — what resources exist, and how do they connect?
  • Cost — what does this cost now, and what would it cost if it grew?
  • Security — what has been done to keep this safe, and what still needs attention?

These three questions map directly onto skills tested in the AZ-900 exam, so writing this documentation also doubles as exam preparation.

💡 Use the Azure Pricing Calculator
Go to azure.microsoft.com/pricing/calculator, search for the service(s) you used (for example "Storage Accounts" or "App Service"), and fill in your configuration and region. On the free tier your actual cost is €0, but the calculator lets you see what the same setup would cost outside the free tier or at a larger scale — which is the number worth documenting.
